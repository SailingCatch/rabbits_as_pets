# Rabbits as Pets

A data visualisation about pet rabbits in Australia: where you can keep one,
where their wild relatives live, and what happens to small pets that end up in
shelters. Built with [Vega-Lite](https://vega.github.io/vega-lite/) for
FIT3179 Data Visualisation 2 (Monash University, Semester 2 2026).
